Introduction to ROS 2 Nodes and Topics

Introduction​

This chapter introduces the fundamental concepts of ROS 2, focusing on nodes and topics. These are the building blocks for creating distributed robotic applications. We will explore what nodes are, how they communicate using topics, and essential ROS 2 commands.

Theory​

ROS 2 (Robot Operating System 2) is a set of software libraries and tools that help you build robot applications. It is designed to be a flexible framework for writing robot software.

Nodes: A node is an executable process that performs computations. Nodes are designed to do one thing well. For example, one node might control a motor, another might process camera data, and another might estimate the robot's position.

Topics: Topics are named buses over which nodes exchange messages. Topics are the most common way for data to flow in ROS 2. Nodes publish messages to a topic, and other nodes subscribe to that topic to receive the messages. This is a many-to-many, anonymous publish/subscribe system.

Code Examples​

Simple Publisher Node (Python)​

This example demonstrates a basic ROS 2 publisher node that sends "Hello World" messages to a topic.

# book-content/shared/code-snippets/ros2-simple-publisher.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class SimplePublisher(Node):
    def __init__(self):
        super().__init__('simple_publisher')
        self.publisher_ = self.create_publisher(String, 'chatter', 10)
        timer_period = 0.5  # seconds
        self.timer = self.create_timer(timer_period, self.timer_callback)
        self.i = 0

    def timer_callback(self):
        msg = String()
        msg.data = f'Hello World: {self.i}'
        self.publisher_.publish(msg)
        self.get_logger().info(f'Publishing: "{msg.data}"')
        self.i += 1

def main(args=None):
    rclpy.init(args=args)
    simple_publisher = SimplePublisher()
    rclpy.spin(simple_publisher)
    simple_publisher.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

Simple Subscriber Node (Python)​

This example shows a basic ROS 2 subscriber node that receives messages from the "chatter" topic.

# book-content/shared/code-snippets/ros2-simple-subscriber.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class SimpleSubscriber(Node):
    def __init__(self):
        super().__init__('simple_subscriber')
        self.subscription = self.create_subscription(
            String,
            'chatter',
            self.listener_callback,
            10)
        self.subscription  # prevent unused variable warning

    def listener_callback(self, msg):
        self.get_logger().info(f'I heard: "{msg.data}"')

def main(args=None):
    rclpy.init(args=args)
    simple_subscriber = SimpleSubscriber()
    rclpy.spin(simple_subscriber)
    simple_subscriber.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

Simulation Exercises​

Exercise 1: Run ROS 2 Publisher and Subscriber​

Objective: To observe inter-node communication via topics in ROS 2.

Steps:

  1. Open two separate terminal windows.
  2. In the first terminal, run the publisher node: 
    ros2 run your_package simple_publisher
    (Note: Replace your_package with the actual name of your ROS 2 package containing the simple_publisher node.)
  3. In the second terminal, run the subscriber node: 
    ros2 run your_package simple_subscriber
  4. Observe the output in both terminals. The publisher should be sending messages, and the subscriber should be receiving them.

Expected Outcome: The subscriber terminal should continuously display messages like "I heard: 'Hello World: X'", where X increments, matching the messages published by the publisher.
